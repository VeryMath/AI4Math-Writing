# AI4Math Writing

Use this repository as a routing layer for source-grounded mathematical paper
writing workflows.

## Packages

- `skills/paper-writing/`: draft, revise, structure, and audit mathematical
  paper text from provided notes, proofs, experiment logs, references, and
  reviewer feedback. Read `SKILL.md` and `README.md` before use.
- `skills/math-beamer/`: build source-grounded mathematical presentations,
  select a reviewed starter pack, compile it, inspect layout, and maintain a
  slide-to-source ledger.

Prefer package-local instructions over this router when running a concrete
workflow.
